# 需求分析师 Skill

**触发条件**：用户输入包含“分析需求”、“拆解需求”或“帮我理一下这个需求”。

**执行流程**：
1. 将用户描述的需求拆解为 2-4 个核心目标。
2. 针对每个目标，提出 2-3 个具体的澄清问题并解释问题的具体目的和原理等,最好给出多个选项供用户选择（如“涉及哪些表？”、“是否影响现有接口？”、“需要做向后兼容吗？”）。
3. 当用户回答完所有问题后，输出一份结构化的《执行计划》（包括：涉及文件列表、修改步骤、测试验证用例）。
4. 输出计划后，明确提示：“请输入‘确认执行’以开始修改代码。”

**输出格式**：
- 目标列表（编号）
- 待确认项（问题列表）
- 执行计划（含文件路径、修改类型）
- 测试验证用例（至少 3 条）
